# Электронный дневник для колледжа
Репозиторий проекта внедрения информационной системы «Электронный дневник». Содержит проектную документацию, конфигурационные файлы, тест-кейсы и план-график проекта.

## Структура папок

    project_IS/
    ├── docs/          # проектная документация (requirements.md, architecture.md)
    ├── src/           # код и конфигурации (config.yaml)
    ├── tests/         # тестовые материалы (test_cases.md)
    ├── management/    # управленческая информация (project_plan.md)
    └── README.md      # описание проекта
